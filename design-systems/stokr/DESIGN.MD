# stokr Design System

## Product
stokr is an AI-powered stock research platform for beginner-to-intermediate investors.

## Design goal
Make stock research feel clearer, faster, and more traceable.

The product should feel like a premium fintech SaaS research tool, not a trading hype app.

## Visual direction
- Linear/Vercel-inspired
- Dark mode first
- Calm, credible, serious
- Premium SaaS feel
- Strong spacing
- Subtle borders
- Clean card system
- Clear hierarchy
- Minimal but not empty
- Source-backed and trustworthy

## Avoid
- Meme-stock visuals
- Casino/trading-app energy
- Fake urgency
- Loud gradients
- Excessive glassmorphism
- Overly rounded bubbly UI
- “Buy/sell” financial advice language
- Guaranteed return language
- Vague AI hype

## Typography
Use the existing project font unless already configured differently.

Recommended scale:
- Hero title: 48px desktop / 36px mobile
- Page title: 32px
- Section title: 20px-24px
- Card title: 14px-16px
- Body: 14px-16px
- Metadata: 12px-13px

## Radius
- Small: 8px
- Cards: 14px
- Large panels: 18px

Avoid overly rounded components.

## Card rules
Cards should:
- Use dark surfaces
- Use subtle borders
- Have clear headings
- Use consistent padding
- Avoid excessive shadow
- Feel practical and information-dense
- Not look decorative for no reason

## Button rules
Primary buttons:
- Teal accent
- Clear action text
- High contrast

Secondary buttons:
- Dark/transparent background
- Subtle border
- Muted text

Danger buttons:
- Use red carefully
- Require clear intent

## Badge rules
Use badges for:
- Risk severity
- Source type
- Filing type
- Plan type
- Confidence/source coverage
- Status

Badges should be compact and low-noise.

## Chart rules
Charts should:
- Live inside clean cards
- Use compact range selectors
- Not overpower the analysis
- Have useful loading states
- Show unavailable states cleanly

## Compliance tone
stokr provides informational research tools only and does not provide financial advice.

Use:
- Potential strength
- Potential concern
- Worth reviewing
- Source-backed summary
- Research signal
- Requires verification
- Informational research only

Avoid:
- Buy
- Sell
- Guaranteed
- Sure thing
- Moon
- Undervalued gem
- Explosive returns
- Beat the market
- Can’t miss
- Financial advice

# stokr Dashboard Redesign Skill

## Goal
Make the dashboard feel like a research command center, not a cluttered collection of cards.

## Required sections
Preserve or improve:

- Greeting/header
- Main stock search
- Analyze stock CTA
- Free/premium usage indicator
- Watchlist preview
- Recent reports
- Popular stocks
- Education/helper cards
- Premium CTA

## Layout
Desktop:
- Main content column
- Right sidebar for usage, education, or premium CTA
- Search should be obvious
- Avoid too many competing top-level cards

Mobile:
- Stack sections
- Keep search prominent
- Cards should be scannable
- No horizontal overflow

## Design rules
- Reduce clutter
- Improve hierarchy
- Make next action obvious
- Popular stocks should feel like research links, not gambling/trading bait
- Premium CTA should be tasteful, not aggressive
